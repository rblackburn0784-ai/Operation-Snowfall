# Snow Don portrait stages

Install the ten existing transparent portraits using:

```powershell
python -m snowfall.graphics.snow_don .\Snow_Don_Health_Transparent.zip
```

Expected files: `snow_don_100.png`, `snow_don_90.png`, ... `snow_don_10.png`.
At 0% health the 10% portrait is used with a DEFEATED label.
This directory is intentionally empty until you supply the pre-created artwork.
