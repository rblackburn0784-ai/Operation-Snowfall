# Visual asset provenance — Operation Snowfall v0.1.5

The six snowy city paintings were generated for this project with OpenAI's
image generation capability in November 2026, then edited and optimised using
Pillow for consistent cards. They are original generated winter-noir scenes,
not photographs or copies of existing games or brand artwork. City-specific
silhouette accents and the eight transparent item icons were drawn using a
project-specific Pillow script, without third-party graphic assets.

The renderer uses common operating-system fonts (DejaVu Sans or Arial) at
runtime and **does not redistribute font files**.

Source assets included inside the Python package:

- `src/snowfall/graphics/art/cities/{chicago,new_york,detroit,philadelphia,las_vegas,los_angeles}.webp`
- `src/snowfall/graphics/art/items/{snowball,cocoa,fort,mittens,bomb,golden,boss,siege}.png`

Do not replace these assets with third-party logos or art without permission.
The images depict **stylised city-inspired environments**, not exact historical
architecture. Event art is not an endorsement or affiliation with MafiaReturns.
