# v2.9.9k1 — Christmas Trivia artwork integration

**Scope:** staging only; no change to server scoring, database, Discord gameplay, or prizes.

## Required artwork

Place these **five** files in `src/snowfall/graphics/art/v290/arcade/v299k1/`:

- `trivia-stage.webp` — supplied Christmas game-show image, 16:9 background
- `trivia-answer-blue.webp` — animated blue present, answer 1
- `trivia-answer-red.webp` — animated red present, answer 2
- `trivia-answer-gold.webp` — animated yellow/gold present, answer 3
- `trivia-answer-green.webp` — animated green present, answer 4

The source GIFs were converted to animated WebP retaining **all six frames**, rather than flattening the animation. The asset ZIP generated in the ChatGPT conversation contains these five WebP files and SHA-256 checksums. **GitHub connector can push text code but cannot read the conversation container's local binary images directly.** These files must be added to this branch before deployment.

## Rendering

- Dedicated stage rendered at 640×360 logical scene resolution.
- Four animated gift cards in existing 2×2 hit regions; colours never encode correct answers.
- Legible dynamic text within the right part of the gifts, leaving the decorative bows clear.
- Selection highlight is visually separate from server grading.
- Question progression, pause/resume, keyboard/touch controls, letter scramble and true/false remain unchanged.
- Graceful fallback to pre-v2.9.9k1 graphics if new files are unavailable; however this fallback **does not count as artwork acceptance**.

## QA gates

1. Upload all five binary assets at the exact paths on this branch.
2. Run the original Trivia browser suite plus `node --test tests/test_v299k1_trivia_art_browser.mjs`.
3. Verify six animated frames in each present, readability for long answer options and mobile touch.
4. Confirm the artwork is served under `/art/v290/arcade/v299k1/` and test without cache.
5. Verify all 3 question types and server-side score/answer validation.
6. Deploy **Snowfall-Web-QA staging only** after checks pass and review.
7. Production release remains blocked until complete Arcade 2.0 acceptance.
